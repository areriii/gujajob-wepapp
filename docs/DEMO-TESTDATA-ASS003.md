## ก่อนกรอกทุกครั้ง — เลือกประเภทครุภัณฑ์

ช่อง **ค้นหาประเภทครุภัณฑ์** อยู่บนสุดของฟอร์ม

1. `ค้นหาจาก` เลือก **รหัสประเภท**
2. พิมพ์รหัสตามตาราง แล้วกด **ค้นหา**
3. คลิกเลือกรายการที่ขึ้นมา

ระบบจะเติม 6 ช่องนี้ให้เอง และแก้ไม่ได้

```
รหัสประเภทครุภัณฑ์  หมวดครุภัณฑ์  ชนิดครุภัณฑ์  ชื่อครุภัณฑ์  หน่วยนับ  อัตราค่าเสื่อม
```

**ถ้าไม่เลือกประเภท กดบันทึกจะขึ้น "กรุณาเลือกประเภทครุภัณฑ์"** — เป็นช่องบังคับช่องเดียวที่พลาดง่าย

ช่องบังคับจริง ๆ มีแค่ **ประเภทครุภัณฑ์** กับ **สถานะ** เท่านั้น ที่เหลือว่างได้หมด

## สิ่งที่ต้องทำครั้งเดียวหลังย้ายเครื่องหรือ clone ใหม่

```
php artisan storage:link
```

รูปครุภัณฑ์เก็บจริงที่ `storage/app/public/asset-images/<id>/` แต่หน้าเว็บเรียกผ่าน `/storage/...`
ถ้าไม่มีลิงก์นี้ **อัปโหลดสำเร็จแต่รูปจะไม่ขึ้น** ช่องรูปจะว่างเฉย ๆ ไม่มี error อะไรบอก
(`public/storage` อยู่ใน .gitignore จึงไม่ติดมากับ repo)

## สรุปข้อควรระวังตอนกรอกสด

| เรื่อง | รายละเอียด |
|---|---|
| ประเภทครุภัณฑ์ | ต้องค้นแล้วคลิกเลือกก่อน ไม่งั้นบันทึกไม่ผ่าน |
| รหัสครุภัณฑ์ประจำหน่วยงาน | ช่องล็อก ไม่ต้องกรอก ระบบกำหนดให้ที่ ASS-005 |
| ช่องวันที่ | ปฏิทิน พ.ศ. รูปแบบ วว-ดด-ปปปป กดที่ช่องแล้วเลือกจากปฏิทิน |
| ผู้ประกอบการ | พิมพ์บางส่วนของชื่อแล้วเลือกจากรายการที่เด้งขึ้นมา |
| รูปภาพ | ไม่เกิน 3 รูปต่อครุภัณฑ์ รูปละไม่เกิน 1 MB เฉพาะ jpg / png / gif |
| มูลค่าคงเหลือ | คำนวณให้อัตโนมัติ แก้เองไม่ได้ |
| หน่วยงานของครุภัณฑ์ | ยึดตามบัญชีที่ล็อกอิน (`user01` = ฝ่ายพัสดุ) |
