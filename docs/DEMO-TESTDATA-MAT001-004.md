# MAT-001 ถึง MAT-004 — ชุดข้อมูลสำหรับกรอกสดตอนพรีเซนต์

ค่าทุกตัวเช็คกับฐานข้อมูลจริงแล้ว รหัสวัสดุไม่ซ้ำของเดิม จำนวนที่เบิกไม่เกินของที่มีในคลัง
ชื่อผู้ประกอบการตรงกับที่มีในระบบ

**บัญชีที่ใช้** `user01` / `1234` — หน่วยงาน **ฝ่ายพัสดุ** (org 382)
ทั้ง 4 หน้าผูกกับหน่วยงานของบัญชีที่ล็อกอิน ถ้าใช้บัญชีอื่นตัวเลขคงเหลือจะไม่ตรงกับที่เขียนไว้นี้

## MAT-001 จัดการรายการวัสดุ

**เส้นทาง** จัดการรายการวัสดุ → ปุ่ม `เพิ่มวัสดุใหม่`

### กติกาของแต่ละช่อง

| ช่อง | บังคับ | เงื่อนไข |
|---|---|---|
| รหัสวัสดุ | ✅ | ไม่เกิน 10 ตัวอักษร **A-Z 0-9 และ `-` เท่านั้น** ห้ามเว้นวรรค ห้ามภาษาไทย ห้ามซ้ำของเดิม ระบบแปลงเป็นตัวพิมพ์ใหญ่ให้เอง |
| ชื่อวัสดุ | ✅ | ไม่เกิน 200 ตัวอักษร |
| รายละเอียด | — | ไม่เกิน 1000 ตัวอักษร |
| หน่วยนับ | ✅ | ไม่เกิน 20 ตัวอักษร |
| จำนวนขั้นต่ำ | — | จำนวนเต็ม ไม่ติดลบ |
| จำนวนสูงสุด | — | จำนวนเต็ม **ต้องไม่น้อยกว่าจำนวนขั้นต่ำ** ไม่งั้นขึ้น error |

> ระบบมีวัสดุอยู่แล้ว 101 รายการ รหัสสูงสุดคือ `MAT-1101` ชุดข้างล่างจึงเริ่มที่ `MAT-1102`
> หน่วยนับที่ระบบใช้อยู่ — กล่อง ขวด คู่ ชิ้น ชุด ด้าม ตลับ ถุง ผืน ม้วน รีม หลอด อัน เล่ม เส้น แท่ง แผ่น แพ็ค ใบ

### รายการที่ 1

```
รหัสวัสดุ        MAT-1102
ชื่อวัสดุ         กระดาษถ่ายเอกสาร A4 70 แกรม
รายละเอียด       กระดาษถ่ายเอกสารสีขาว ขนาด A4 ความหนา 70 แกรมต่อตารางเมตร
                 บรรจุรีมละ 500 แผ่น ใช้ได้กับเครื่องถ่ายเอกสารและเครื่องพิมพ์เลเซอร์
หน่วยนับ         รีม
จำนวนขั้นต่ำ      20
จำนวนสูงสุด       400
```

### รายการที่ 2

```
รหัสวัสดุ        MAT-1103
ชื่อวัสดุ         หมึกพิมพ์เลเซอร์ขาวดำ รุ่น 85A
รายละเอียด       ตลับหมึกพิมพ์เลเซอร์ชนิดขาวดำ ของแท้จากผู้ผลิต
                 พิมพ์ได้ประมาณ 1,600 แผ่นต่อตลับ ใช้กับเครื่องพิมพ์เลเซอร์ในสำนักงาน
หน่วยนับ         ตลับ
จำนวนขั้นต่ำ      5
จำนวนสูงสุด       40
```

### รายการที่ 3

```
รหัสวัสดุ        MAT-1104
ชื่อวัสดุ         แฟ้มสันกว้าง 3 นิ้ว ชนิดมีห่วง
รายละเอียด       แฟ้มเก็บเอกสารชนิดสันกว้าง 3 นิ้ว ปกแข็งหุ้มพลาสติก
                 มีห่วงโลหะ 2 ห่วง พร้อมช่องใส่ป้ายชื่อที่สัน
หน่วยนับ         เล่ม
จำนวนขั้นต่ำ      10
จำนวนสูงสุด       60
```

### รายการที่ 4 — เอาไว้โชว์ error ถ้าอยากเล่าเรื่อง validation

```
รหัสวัสดุ        MAT 1105        ← มีเว้นวรรค ระบบจะไม่รับ
จำนวนขั้นต่ำ      50
จำนวนสูงสุด       10             ← น้อยกว่าขั้นต่ำ ระบบจะไม่รับ
```

แก้เป็น `MAT-1105` และสลับเป็นขั้นต่ำ 10 สูงสุด 50 แล้วบันทึกผ่าน
ชื่อ `ซองเอกสารสีน้ำตาล ขนาด A4` หน่วยนับ `ใบ`

## MAT-002 บันทึกการรับวัสดุเข้าคลัง

**เส้นทาง** บันทึกการรับวัสดุเข้าคลัง → ปุ่ม `บันทึกการรับวัสดุใหม่`

**เลขที่ใบรับวัสดุระบบออกให้เอง** ช่องนั้นล็อกไว้ ไม่ต้องกรอก

### ส่วนหัวใบรับ

| ช่อง | ค่าที่กรอก |
|---|---|
| วันที่รับวัสดุ * | `18-11-2569` |
| หน่วยงานที่รับเข้า * | `ฝ่ายพัสดุ` |
| ผู้ประกอบการ * | `บริษัท ออฟฟิศพลัส (ประเทศไทย) จำกัด` |
| วิธีการจัดซื้อจัดจ้าง | `เฉพาะเจาะจง` |
| หมายเลขใบเสนอราคา | `QT-2569/0418` |
| เลขที่สัญญา | `ซอ-2569/0231` |
| วันที่ของสัญญา | `05-11-2569` |
| ภาษีมูลค่าเพิ่ม | `ไม่รวม VAT` · อัตราภาษี `7` |

> **ตัวเลือก VAT มี 3 แบบ** รวม VAT · ไม่รวม VAT · ไม่มีภาษี
> ถ้าเลือก *ไม่มีภาษี* ช่องอัตราภาษีจะถูกปิด อัตราที่เลือกได้มีแค่ 7 กับ 10
> **ตัวเลือกวิธีจัดซื้อ** เฉพาะเจาะจง · ประกวดราคา · คัดเลือก

### รายการวัสดุที่รับ

ค้นหาวัสดุ → เลือก → กรอกจำนวนกับราคา → กด **เพิ่ม** ทีละรายการ

| ลำดับ | ค้นด้วยรหัส | ชื่อที่จะขึ้นมา | จำนวน | ราคา/หน่วย |
|---|---|---|---|---|
| 1 | `MAT-1001` | กระดาษถ่ายเอกสาร A4 80 แกรม | `120` | `48.50` |
| 2 | `MAT-1005` | ปากกาลูกลื่นสีดำ 0.7 มม. | `200` | `15.00` |
| 3 | `MAT-1009` | ดินสอดำ 2B | `150` | `5.50` |
| 4 | `MAT-1023` | สมุดบันทึกปกแข็ง A5 | `80` | `25.00` |

รวมก่อน VAT = **10,110.00 บาท** · VAT 7% = 707.70 · รวมทั้งสิ้น **10,817.70 บาท**

ถ้าอยากให้เร็วขึ้นใช้แค่ 2 รายการแรกก็พอ (รวมก่อน VAT 8,820.00)

> **ชื่อวัสดุ หน่วยนับ ระบบเติมให้เอง** หลังเลือกจากผลค้นหา กรอกเองไม่ได้
> ต้องกด **เพิ่ม** ทุกครั้ง ไม่งั้นรายการจะไม่เข้าตาราง แล้วบันทึกไม่ผ่านเพราะต้องมีอย่างน้อย 1 รายการ

**บันทึกใบนี้แล้วยอดคงเหลือในคลังจะเพิ่มขึ้นจริง** ต่อยอดโชว์ที่ MAT-005 คุมทะเบียนวัสดุ
หรือ MAT-006 บันทึกการตั้งยอดคงเหลือได้เลย

## MAT-003 เบิกวัสดุ

**เส้นทาง** เบิกวัสดุ → เลือกปุ่มใดปุ่มหนึ่ง

มี **2 แบบ** และผลต่างกันมาก เลือกให้ถูกก่อน

| ปุ่ม | ความหมาย | หลังบันทึก |
|---|---|---|
| **เบิกภายในหน่วยงาน** | ตัดของจากคลังของหน่วยงานตัวเอง | ยอดคงเหลือลดทันที |
| **เบิกวัสดุจากหน่วยงานต้นสังกัด** | ขอเบิกจากคลังกลาง | ต้องรออนุมัติ แล้วไปรับที่ MAT-004 |

### ชุดที่ 1 — เบิกภายในหน่วยงาน

| ช่อง | ค่าที่กรอก |
|---|---|
| เลขที่ใบเบิก | *(ระบบออกให้เอง ไม่ต้องกรอก)* |
| วันที่เบิก * | `18-11-2569` |
| หน่วยงานที่ขอเบิก * | *(ล็อกเป็น ฝ่ายพัสดุ ตามบัญชีที่ล็อกอิน)* |
| ชื่อผู้เบิกวัสดุ * | `นางสาวกนกวรรณ สุขประเสริฐ` |

รายการที่เบิก — ค้นหาด้วยรหัส แล้วกด **เพิ่ม**

| ค้นด้วยรหัส | ชื่อวัสดุ | หน่วย | **คงเหลือตอนนี้** | เบิก |
|---|---|---|---|---|
| `MAT-1001` | กระดาษถ่ายเอกสาร A4 80 แกรม | รีม | 228 | `30` |
| `MAT-1005` | ปากกาลูกลื่นสีดำ 0.7 มม. | ด้าม | 309 | `50` |
| `MAT-1010` | ยางลบดินสอชนิดนุ่ม | อัน | 145 | `20` |

> **จำนวนที่เบิกต้องไม่เกินยอดคงเหลือ** ไม่งั้นขึ้น
> *"วัสดุ MAT-1001: จำนวนที่เบิก (300) เกินจำนวนคงเหลือ (228)"*
> ตัวเลขคงเหลือข้างบนคือ ณ ตอนที่เขียนเอกสารนี้ ถ้าเดโมเบิกไปแล้วหลายรอบจะลดลง
> **เผื่อไว้ให้แล้ว** ทุกตัวเบิกไม่ถึง 1 ใน 4 ของที่มี เบิกซ้ำได้หลายรอบไม่สะดุด

### ชุดที่ 2 — เบิกจากหน่วยงานต้นสังกัด *(ชุดที่ควรใช้โชว์)*

| ช่อง | ค่าที่กรอก |
|---|---|
| วันที่เบิก * | `18-11-2569` |
| ชื่อผู้เบิกวัสดุ * | `นายพิชัย ทองแท้` |

| ค้นด้วยรหัส | ชื่อวัสดุ | เบิก |
|---|---|---|
| `MAT-1003` | กระดาษถ่ายเอกสาร A3 80 แกรม | `40` |
| `MAT-1007` | ปากกาเน้นข้อความสีเหลือง | `25` |

**ทำไมชุดนี้ดีกว่าสำหรับพรีเซนต์** มันเดินครบวงจร
เบิก (MAT-003) → อนุมัติการเบิกวัสดุ → **รับโอนวัสดุ (MAT-004)** เล่าได้ยาวต่อเนื่อง 3 หน้าจอ

### ชุดที่ 3 — เอาไว้โชว์ว่าระบบกันของไม่พอ

```
MAT-1009  ดินสอดำ 2B   คงเหลือ 55   ลองเบิก 500
```

ระบบจะไม่ยอมให้บันทึก พร้อมบอกยอดคงเหลือจริง

## MAT-004 รับโอนวัสดุ

**หน้านี้ไม่มีฟอร์มสร้างใหม่** — มันคือปลายทางของใบเบิกแบบ *เบิกจากหน่วยงานต้นสังกัด*
ที่ผ่านการอนุมัติแล้ว จึงกรอกสดจากศูนย์ไม่ได้ ต้องมีใบเบิกมาก่อน

**ลำดับที่ต้องทำ**

1. MAT-003 เบิกวัสดุ → เลือก **เบิกวัสดุจากหน่วยงานต้นสังกัด** → ใช้ชุดที่ 2 ข้างบน
2. เมนู **อนุมัติการเบิกวัสดุ** → อนุมัติใบนั้น
3. เมนู **รับโอนวัสดุ** → ใบจะมาโผล่ที่นี่ → กดเข้าไปบันทึกการรับ

### ช่องที่กรอกตอนรับโอน

| ช่อง | บังคับ | ค่าที่กรอก |
|---|---|---|
| เลขที่ใบเบิก | — | *(ล็อก มาจากใบเบิก)* |
| หมายเลขรับโอน | — | *(ระบบออกให้เอง)* |
| วันที่รับโอน | ✅ | `19-11-2569` |
| ชื่อผู้รับโอนวัสดุ | ✅ | `นางสาวกนกวรรณ สุขประเสริฐ` |
| หมายเหตุ | — | `ตรวจนับแล้วครบตามใบเบิก สภาพเรียบร้อย รับเข้าคลังหน่วยงานเรียบร้อย` |
| จำนวนที่รับจริง (รายรายการ) | ✅ | กรอกเท่าที่ขอ หรือน้อยกว่าถ้าจะโชว์กรณีรับไม่ครบ |

**ถ้าอยากเล่ากรณีรับไม่ครบ** ใบที่ขอ A3 ไว้ 40 ให้กรอกรับจริง `35`
แล้วหมายเหตุเป็น

```
รับจริง 35 รีม ขาด 5 รีม เนื่องจากคลังกลางมีของไม่พอ
ได้แจ้งเจ้าหน้าที่คลังกลางให้จัดส่งส่วนที่เหลือในรอบถัดไป
```

> หน้ารับโอนวัสดุตอนนี้มีใบเบิกอยู่ **53 รายการ** (เริ่มที่ MWD-6800001) และบันทึกการรับไปแล้ว 46 ใบ
> ถ้าไม่อยากเดินครบ 3 ขั้น เปิดใบเดิมดูได้เลย แต่ถ้าจะโชว์การกรอกสด ต้องเริ่มจาก MAT-003 เท่านั้น
