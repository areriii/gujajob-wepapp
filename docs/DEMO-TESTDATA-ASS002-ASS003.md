# ข้อมูลสำหรับกรอกสดตอนพรีเซนต์ — ASS-002 / ASS-003

ชุดนี้ทำไว้ให้ **พิมพ์เองหน้าเวที** ไม่ต้องรัน seed ทุกค่าตรวจแล้วว่าผ่าน validation
และอ้างถึงข้อมูลที่มีอยู่จริงในฐานข้อมูล (จังหวัด/อำเภอ/ตำบล และรหัสประเภทครุภัณฑ์)

> ชื่อบริษัท เลขประจำตัวผู้เสียภาษี เลขที่สัญญา และหมายเลขเครื่อง ทั้งหมดเป็นของสมมติ

## ASS-002 — จัดการข้อมูลผู้ประกอบการ

**เส้นทาง** จัดการข้อมูลผู้ประกอบการ → ปุ่ม `บันทึกผู้ประกอบการใหม่`

มี **2 ช่องที่บังคับ** คือ ประเภทผู้ประกอบการ กับ ชื่อผู้ประกอบการ ที่เหลือว่างได้
แต่ถ้าจะโชว์ให้ครบควรกรอกหมด

> **ลำดับการกรอกที่อยู่สำคัญ** ต้องเลือก **จังหวัด → อำเภอ → ตำบล** ตามลำดับ
> เพราะรายการอำเภอกรองตามจังหวัดที่เลือก และตำบลกรองตามอำเภอ
> ถ้าข้ามไปเลือกตำบลก่อนจะไม่มีตัวเลือกขึ้นมา

## ASS-003 — จัดการทะเบียนครุภัณฑ์

**เส้นทาง** จัดการทะเบียนครุภัณฑ์ → ปุ่ม `บันทึกทะเบียนใหม่`

### ขั้นตอนที่ต้องทำก่อนเสมอ

1. ช่อง **ค้นหาประเภทครุภัณฑ์** ด้านบนสุด เลือก `ค้นหาจาก` = **รหัสประเภท**
2. พิมพ์รหัสตามตารางข้างล่าง แล้วกด **ค้นหา** → เลือกจากรายการ
3. ระบบจะเติม **รหัสประเภท / หมวด / ชนิด / ชื่อครุภัณฑ์ / หน่วยนับ / อัตราค่าเสื่อม** ให้เอง
   ทั้ง 6 ช่องนี้แก้ไม่ได้ ถ้าไม่เลือกประเภทจะบันทึกไม่ผ่าน

> **รหัสครุภัณฑ์ประจำหน่วยงาน** ไม่ต้องกรอก ช่องนี้ล็อกไว้แล้ว
> ระบบจะกำหนดให้ตอน ASS-005 รับครุภัณฑ์ลงทะเบียนหน่วยงาน

> **ช่องวันที่** เป็นปฏิทิน พ.ศ. แสดงแบบ `วว-ดด-ปปปป` กดที่ช่องแล้วเลือกจากปฏิทินได้เลย
